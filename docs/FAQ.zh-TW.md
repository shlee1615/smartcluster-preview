# 常見問題與排錯

[首頁](../README.zh-TW.md) · [English](FAQ.en.md) · [使用手冊](USER_GUIDE.zh-TW.md)

## SmartCluster 自帶 AI 嗎？

不自帶模型訂閱。診斷示範不使用 AI；真實分析由目標電腦已安裝、登入且啟用的官方 Claude／Codex CLI 執行，消耗該帳號的額度。App 接收器是另一種工作通道，不等同 CLI 分析。

## 只用對話就可以操作嗎？

支援本機 stdio MCP 的客戶端完成連接後，可以查節點、派工、追蹤與操作已支援的本機服務／邀請功能。建立與切換群組仍使用網頁介面。AI 只回答操作建議時，先檢查工具是否載入、是否允許呼叫，以及有沒有實際結果。

## 查看其他群，會送錯工作嗎？

「查看」不改接單。MCP 綁定指定的本機 profile，不隨 UI 選取或接單群改變。同一 registry 一次一個接單群；這不是全機所有獨立安裝的共同鎖。每次派工仍應核對群組與目標。

## App 工作為什麼一直排隊？

先確認接收器已連接、來源和專案在授權範圍內，再確認 App 有收件活動。Node 在線或工作提交成功不代表 App 已醒來。預览不保證閒置 App 自動喚醒；既有外部排程也需分別管理。

## 加入代表把整台電腦開放嗎？

不會。群組配對、AI 登入、專案授權、檔案交付與 App 收件分開設定。群主不能因為你加入就擴大本機授權。mTLS 驗證的是裝置／節點，不能當作完整的人員角色管理。

## 資料會傳到哪裡？

派工內容及結果會由協作鏈路處理並依功能保存；AI 分析會將你提交的內容交給目標節點及所選 AI 服務。完整 App 歷史留在原電腦。只分享當次工作必要內容；不要在公開 issue 附上原始工作資料、邀請或憑證。

## 常見故障

| 現象 | 處理 |
|---|---|
| 管理頁失效或要求登入 | 從 EXE 重新取得本機入口，不分享含登入資訊的 URL |
| 服務顯示可接單卻未執行 | 先啟動服務，再查健康狀態與診斷結果 |
| AI 查到不同群組 | 核對 MCP 的 profiles-dir 及 profile_id；不是 cluster_id |
| 加入逾時 | 核對版本、Hub 位址與實際埠、路由及允許的防火牆規則 |
| 邀請或憑證不符 | 向群主重新核對來源、時間及指紋，不跳過 TLS 驗證 |
| 加入過程中斷 | 優先接續現有加入紀錄；不要連續新增身分 |
| 切換一直等候 | 核對原群未結任務；完成後繼續，或取消切換 |
| 結果待核對 | 查實際產物與程序，保留紀錄，不自動重做副作用 |
| 找不到舊群 | 新 registry 不會自動匯入舊安裝；保留原資料 |
| EXE 被系統攔截 | 候選版未簽署，核對来源及校驗值後找維護者／IT，不關閉防護 |

## 可以直接商業部署嗎？

目前仍是開發候選版，產品授權、支援與服務承諾尚未公布。第三方 AI 和 VPN 方案各有自己的條款；請依用途核對，不要把預览或第三方免費方案視為商業使用許可。[WAN 指引](WAN.zh-TW.md)

## 執行檔封裝是否能保護原始碼？

不能保證。目前內部 dev3 EXE 經檢查含有 29 個可讀取且與原始碼相同的 HTML／CSS／JavaScript 資產，以及 29 個產品 Python 位元組碼模組。PyInstaller 封裝不提供程式內容保密：網頁資產可以抽出，位元組碼可能被分析或反編譯。儲存庫不另附 Python 原始檔；擁有者已決定在揭露上述逆向限制的前提下公開執行檔試用。壓縮、混淆或原生編譯可增加分析成本，但不能保證交付到使用者電腦的程式永遠保密。

## 如何回報？

使用公開展示倉庫提供的問題模板（待倉庫上線後）。提供版本、作業系統、單機／LAN／WAN、重現步驟、預期與實際結果、遮敏後的錯誤代碼。截圖先去除帳號、IP、路徑、任務內容及短效登入資料。沒有自動遮敏匯出功能。發現敏感問題時，先請維護者提供私下回報方式，不公開漏洞利用細節或秘密。
