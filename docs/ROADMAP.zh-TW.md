以下為後續規劃，不是第一個預覽版承諾已具備的功能，尚未承諾交付日期。

## 目標電腦的可見執行過程

在目標電腦呈現真正支援的執行介面：任務收件、可取得的進度或工具輸出，以及最終結果。以同一任務識別碼串起主對話、執行端畫面與 Hub 紀錄。背景 CLI 任務不會自動顯示在既有 Claude 桌面對話中。

驗收應包含成功、失敗、取消狀態、斷線重連及私人內容遮罩。只呈現實際可觀察輸出，不製造 Agent 內部推理，也不把模擬對話當成執行證據。之後的展示可並列主 Agent 與執行 Agent，並說明拍攝時間關係。

## 其他後續項目

- 驗證客戶自有企業 VPN 與其他網路路徑；目前以客戶自行管理的 Tailscale 指引為主。
- 改善更新、恢復及去識別診斷流程。
- 評估更完整群組管理及人員角色，與現有裝置身分驗證分開設計。

正式生產發行前，目前公開試用版仍需完成相依套件聲明及產品條款、決定簽署／發行方式，並完成乾淨機驗收。詳見[版本狀態](RELEASE_NOTES.zh-TW.md)。
