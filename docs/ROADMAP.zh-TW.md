# Preview 2 之後

[首頁](../README.zh-TW.md) · [English](ROADMAP.en.md)

以下是下一輪優先順序，不是本候選版已提供的功能，也尚未承諾日期。先完成本版的套件、乾淨帳號與跨實體機驗收，再逐項開發。

## 1. 降低執行節點的安裝門檻

先補齊 Windows 執行檔部署的 Gemini CLI／App 自動收件與隔離開發路徑，沿用既有授權、驗收、sandbox 與任務流程。工具鏈與 helper 必須確實可用，不能只移除 frozen 保護。完成後以新安裝節點實測派工、寫檔、測試、取消與回報，再擴展 macOS 的封裝與驗收。

## 2. 整包更新與失敗回復

原始碼安裝已有簽署發佈及逐台更新；執行檔目前仍手動更新。下一步以分離的 helper 下載驗簽、等待閒置、替換整包、確認健康，失敗時恢復程式與相容資料。另驗證更新中斷後的恢復，保留原帳號、設定及工作資料。

## 3. 更清楚地看見工作進度

用同一任務識別碼串起發起對話、執行端與 Hub，區分收件、執行、等待核准、測試、回報及待核對。只顯示真正取得的進度，不把背景 CLI 畫面假裝成原生 App 對話。驗收成功、失敗、取消、斷線重連與私人資訊遮罩。

程式碼簽章、macOS 公證、去識別診斷與更多網路路徑依試用結果安排。手機、語音及更大的 Agent 框架不作本輪前置條件。[目前支援範圍](RELEASE_NOTES.zh-TW.md)
