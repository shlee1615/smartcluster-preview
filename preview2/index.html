管理與派工端
  • 解壓完整資料夾後啟動，無須另裝 Python。
  • 管理群組、節點、任務與結果；提供 MCP 操作入口。

Agent 與開發環境
  • 官方 Agent 安裝、帳號登入及逐節點／專案授權。
  • Gemini CLI、自動收件安裝與隔離開發目前需要原始碼執行節點；未包含在此套件。
  • Gemini App 需開啟；原生工具核准仍依 App 設定。
  • CTE bridge 尚不支援再分工、Hub 覆寫模型或完整用量統計。
其他試用限制與驗收範圍
此為限邀請候選版本，免 Python 乾淨帳號及跨實體機新版驗收仍待完成。執行檔更新與回復採手動操作；未提供 macOS 執行檔。CLI 模型與桌面 App 模型分別設定。網頁資產與封裝位元組碼可讀，封裝不提供防逆向保證。Windows 原生 Computer Use 的網址辨識問題未解決，不列為本版支援能力。
